# 内核源码获取与编译

> [!info] 目标
> 获取Linux内核源码并完成编译，理解内核构建过程

## 源码获取

### 方式一：官方源码

```bash
# 从kernel.org获取稳定版
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.6.tar.xz
tar -xvf linux-6.6.tar.xz
cd linux-6.6
```

### 方式二：Git仓库

```bash
# 克隆官方仓库
git clone https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git

# 或使用镜像
git clone https://github.com/torvalds/linux.git
```

### 方式三：发行版源码

```bash
# Ubuntu
apt source linux-image-$(uname -r)

# Fedora
dnf download --source kernel
```

## 源码目录结构

```
linux/
├── arch/          # 架构相关代码 (x86, arm, riscv等)
├── block/         # 块设备层
├── certs/         # 证书文件
├── crypto/        # 加密API
├── Documentation/ # 文档
├── drivers/       # 设备驱动
├── fs/            # 文件系统
├── include/       # 头文件
├── init/          # 初始化代码
├── ipc/           # 进程间通信
├── kernel/        # 核心子系统
├── lib/           # 内核库
├── mm/            # 内存管理
├── net/           # 网络协议栈
├── samples/       # 示例代码
├── scripts/       # 构建脚本
├── security/      # 安全框架
├── sound/         # 音频子系统
├── tools/         # 工具程序
├── usr/           # initramfs
└── virt/          # 虚拟化
```

## 内核配置

### 配置方式

```bash
# 基于当前系统配置
make localmodconfig

# 交互式菜单配置
make menuconfig

# 图形界面配置
make xconfig

# 使用默认配置
make defconfig
```

### 关键配置选项

| 配置项 | 说明 |
|--------|------|
| CONFIG_DEBUG_INFO | 调试符号 |
| CONFIG_DEBUG_KERNEL | 调试选项 |
| CONFIG_KGDB | KGDB内核调试 |
| CONFIG_MAGIC_SYSRQ | 魔术SysRq键 |

## 编译内核

```bash
# 并行编译（N为CPU核心数）
make -j$(nproc)

# 编译内核模块
make modules

# 安装模块
sudo make modules_install

# 安装内核
sudo make install
```

## 编译时间优化

```bash
# 使用ccache加速
sudo apt install ccache
export CC="ccache gcc"

# 增量编译
# 只编译修改的部分
make -j$(nproc)
```

## 验证编译结果

```bash
# 检查生成的内核映像
ls -lh arch/x86/boot/bzImage

# 查看内核版本
make kernelversion

# 检查模块
ls /lib/modules/$(make kernelrelease)/
```
