# 内核调试技术

> [!info] 目标
> 掌握Linux内核的多种调试方法

## 调试方法概览

| 方法       | 适用场景   | 复杂度 |
| -------- | ------ | --- |
| printk   | 简单信息输出 | 低   |
| ftrace   | 函数追踪   | 中   |
| kprobes  | 动态探针   | 高   |
| KGDB     | 源码级调试  | 高   |
| QEMU+GDB | 虚拟机调试  | 中   |
| eBPF     | 动态追踪   | 高   |

## printk调试

### 基本使用

```c
#include <linux/printk.h>

// 日志级别
printk(KERN_INFO "信息消息\n");
printk(KERN_WARNING "警告消息\n");
printk(KERN_ERR "错误消息\n");

// 推荐使用pr_*宏
pr_info("信息\n");
pr_warn("警告\n");
pr_err("错误\n");
pr_debug("调试信息\n");  // 需要启用DEBUG
```

### 日志级别

| 级别 | 宏 | 说明 |
|------|-----|------|
| 0 | KERN_EMERG | 系统不可用 |
| 1 | KERN_ALERT | 必须立即处理 |
| 2 | KERN_CRIT | 严重错误 |
| 3 | KERN_ERR | 错误 |
| 4 | KERN_WARNING | 警告 |
| 5 | KERN_NOTICE | 正常但重要 |
| 6 | KERN_INFO | 信息 |
| 7 | KERN_DEBUG | 调试信息 |

### 查看日志

```bash
# 查看内核日志
dmesg

# 实时监控
dmesg -w

# 查看特定级别
dmesg -l err,warn
```

## ftrace函数追踪

### 启用ftrace

```bash
# 挂载tracefs
mount -t tracefs nodev /sys/kernel/tracing

# 或使用
mount -t debugfs nodev /sys/kernel/debug
```

### 追踪函数调用

```bash
# 进入tracing目录
cd /sys/kernel/tracing

# 设置要追踪的函数
echo schedule > set_ftrace_filter

# 启用追踪
echo function > current_tracer
echo 1 > tracing_on

# 查看结果
cat trace

# 停止追踪
echo 0 > tracing_on
```

## KGDB内核调试

### 内核配置

```
CONFIG_KGDB=y
CONFIG_KGDB_SERIAL_CONSOLE=y
CONFIG_DEBUG_INFO=y
```

### QEMU+KGDB

```bash
# 启动QEMU（等待GDB连接）
qemu-system-x86_64 -kernel arch/x86/boot/bzImage \
    -append "kgdboc=ttyS0,115200 kgdbwait" \
    -serial stdio

# GDB连接
gdb vmlinux
(gdb) target remote localhost:1234
```

## GDB调试内核模块

```bash
# 获取模块加载地址
cat /sys/module/<module_name>/sections/.text

# GDB中加载符号
(gdb) add-symbol-file <module.ko> <address>
```

## 动态调试（Dynamic Debug）

```bash
# 启用动态调试
echo 8 > /proc/sys/kernel/printk

# 控制特定文件/模块的调试输出
echo 'module mymodule +p' > /sys/kernel/debug/dynamic_debug/control
echo 'file mydriver.c +p' > /sys/kernel/debug/dynamic_debug/control
```

## 常用调试技巧

### Oops分析

```bash
# 解析内核崩溃信息
# 需要vmlinux和System.map
crash /usr/lib/debug/boot/vmlinux-$(uname -r) /var/crash/vmcore
```

### /proc文件系统

```bash
# 查看内存信息
cat /proc/meminfo

# 进程信息
cat /proc/<pid>/status
cat /proc/<pid>/maps

# 内核统计
cat /proc/stat
```

### sysrq魔术键

```bash
# 启用sysrq
echo 1 > /proc/sys/kernel/sysrq

# 触发调试信息
echo t > /proc/sysrq-trigger  # 显示任务状态
echo m > /proc/sysrq-trigger  # 显示内存信息
echo w > /proc/sysrq-trigger  # 显示阻塞任务
```
