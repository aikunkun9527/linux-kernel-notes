# 开发环境搭建

> [!info] 目标
> 搭建完整的Linux内核学习与开发环境

## 必备工具

### 1. 操作系统选择
- **推荐发行版**：Ubuntu 22.04/24.04 LTS 或 Fedora
- 备选：在Windows上使用WSL2

### 2. 开发工具链

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install build-essential libncurses-dev bison flex libssl-dev libelf-dev

# 内核编译相关
sudo apt install gcc make bc dwarves git
```

### 3. 调试工具

| 工具    | 用途     | 安装命令                               |
| ----- | ------ | ---------------------------------- |
| gdb   | 用户态调试  | `sudo apt install gdb`             |
| qemu  | 虚拟机调试  | `sudo apt install qemu-system-x86` |
| crash | 内核崩溃分析 | `sudo apt install crash`           |
| kgdb  | 内核调试   | 内核配置启用                             |

### 4. 文档查看工具

```bash
# 内核文档依赖
sudo apt install python3-sphinx sphinx-rtd-theme-common

# 源码导航
sudo apt install cscope universal-ctags
```

## 源码阅读环境

### VSCode配置
推荐扩展：
- C/C++ (Microsoft)
- C/C++ Intellisense
- Linux Kernel Intellisense

### Vim配置（可选）
使用cscope和ctags进行代码导航

## 验证环境

```bash
# 检查编译工具链
gcc --version
make --version

# 检查内核头文件
ls /lib/modules/$(uname -r)/build
```
