## 四、实验结论

### 1. 进程地址空间组成

- **代码段**: 存储可执行指令 (r-xp)
- **数据段**: 存储全局变量 (rw-p)
- **堆 (heap)**: 动态内存分配区域 (rw-p)
- **栈 (stack)**: 函数调用、局部变量 (rw-p)
- **VDSO**: 内核虚拟动态共享对象
- **VSYSCALL**: 快速系统调用

### 2. VMA特点

- 每个VMA代表一段连续的虚拟地址空间
- 具有相同的权限和属性
- 文件映射和匿名映射的VMA权限不同

### 3. 内存分布规律

- 低地址: 代码段、只读数据
- 中等地址: 堆（向上增长）
- 高地址: 栈（向下增长）
- 最高地址: 内核特殊区域

## 六、思考题

1. **什么是VMA？**
   → VMA（Virtual Memory Area）是进程虚拟地址空间中的一个连续区域，具有相同的访问权限和属性。

2. **malloc和mmap有什么区别？**
   - malloc: 分配堆内存，使用brk/sbrk系统调用
   - mmap: 直接映射虚拟内存，可以是匿名映射或文件映射

3. **为什么需要VDSO？**
   → VDSO (Virtual Dynamic Shared Object) 提供内核函数的快速调用接口，减少系统调用开销。
