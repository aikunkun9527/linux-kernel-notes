# Linux内核架构总览

> [!info] 目标
> 理解Linux内核的整体架构设计

## 内核设计理念

### 宏内核（Monolithic Kernel）

Linux采用宏内核设计：
- 所有核心服务运行在同一个地址空间
- 高效的系统调用和数据传递
- 模块化设计弥补扩展性不足

```
┌─────────────────────────────────────┐
│           用户空间                   │
├─────────────────────────────────────┤
│  应用程序  │  库  │  Shell          │
├─────────────────────────────────────┤
│           系统调用接口               │
├─────────────────────────────────────┤
│              内核空间                │
│  ┌─────────────────────────────┐    │
│  │        VFS / 网络 / IPC     │    │
│  ├─────────────────────────────┤    │
│  │   进程管理 │ 内存管理        │    │
│  ├─────────────────────────────┤    │
│  │     设备驱动 │ 文件系统      │    │
│  ├─────────────────────────────┤    │
│  │        硬件抽象层            │    │
│  └─────────────────────────────┘    │
├─────────────────────────────────────┤
│            硬件                     │
└─────────────────────────────────────┘
```

## 核心子系统

### 1. 进程调度器（Process Scheduler）
- 负责CPU时间分配
- 完全公平调度器（CFS）
- 实时调度支持

### 2. 内存管理器（Memory Manager）
- 虚拟内存管理
- 物理内存分配
- 内存映射

### 3. 虚拟文件系统（VFS）
- 统一的文件接口
- 支持多种文件系统
- 页缓存机制

### 4. 网络协议栈
- TCP/IP协议实现
- Socket接口
- 网络设备抽象

### 5. 设备驱动
- 字符设备
- 块设备
- 网络设备

### 6. 进程间通信（IPC）
- 管道、FIFO
- 共享内存
- 信号量、消息队列

## 内核关键特性

### 抢占式内核
- CONFIG_PREEMPT：支持内核抢占
- CONFIG_PREEMPT_RT：实时内核补丁

### SMP支持
- 对称多处理器
- 每CPU变量
- 负载均衡

### 模块化设计
```bash
# 查看已加载模块
lsmod

# 加载模块
insmod module.ko

# 卸载模块
rmmod module
```
