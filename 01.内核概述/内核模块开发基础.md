# 内核模块开发基础

> [!info] 目标
> 掌握Linux内核模块的基本开发方法

## 内核模块简介

内核模块（Kernel Module）是可在运行时加载到内核的代码，用于：
- 添加设备驱动
- 扩展内核功能
- 文件系统支持

## Hello World模块

### 源码（hello.c）

```c
#include <linux/init.h>
#include <linux/module.h>
#include <linux/kernel.h>

// 模块许可证（必需）
MODULE_LICENSE("GPL");
MODULE_AUTHOR("Your Name");
MODULE_DESCRIPTION("A simple kernel module");
MODULE_VERSION("0.1");

// 初始化函数
static int __init hello_init(void) {
    printk(KERN_INFO "Hello, Kernel!\n");
    return 0;  // 返回0表示成功
}

// 清理函数
static void __exit hello_exit(void) {
    printk(KERN_INFO "Goodbye, Kernel!\n");
}

// 注册入口和出口
module_init(hello_init);
module_exit(hello_exit);
```

### Makefile

```makefile
obj-m += hello.o

KDIR := /lib/modules/$(shell uname -r)/build
PWD := $(shell pwd)

all:
	make -C $(KDIR) M=$(PWD) modules

clean:
	make -C $(KDIR) M=$(PWD) clean
```

## 编译与管理

```bash
# 编译
make

# 加载模块
sudo insmod hello.ko

# 查看模块
lsmod | grep hello

# 查看日志
dmesg | tail

# 卸载模块
sudo rmmod hello
```

## 模块信息宏

```c
MODULE_LICENSE("GPL");           // 必需

MODULE_VERSION("版本");
MODULE_ALIAS("别名");
```

## 参数传递

```c
#include <linux/moduleparam.h>

static int count = 1;
static char *name = "default";

module_param(count, int, 0644);
MODULE_PARM_DESC(count, "计数参数");

module_param(name, charp, 0644);
MODULE_PARM_DESC(name, "名称参数");
```

加载时传递参数：
```bash
sudo insmod hello.ko count=5 name="test"
```

## 常用内核API

### 内存分配

```c
#include <linux/slab.h>

void *ptr;
ptr = kmalloc(size, GFP_KERNEL);  // 可睡眠
ptr = kmalloc(size, GFP_ATOMIC);  // 原子上下文
kfree(ptr);
```

### 字符串操作

```c
#include <linux/string.h>

char dest[32];
strcpy(dest, src);
snprintf(dest, sizeof(dest), "value: %d", val);
```

## 导出符号

```c
// 导出函数供其他模块使用
EXPORT_SYMBOL(my_function);
EXPORT_SYMBOL_GPL(my_gpl_function);  // 仅GPL模块可用
```

## 注意事项

> [!warning] 内核编程规范
> - **不能使用标准C库**（无printf，用printk）
> - **不能使用浮点数**
> - **必须检查返回值**
> - **注意内存泄露**
> - **避免长时间阻塞**

## 调试技巧

```c
// 调试打印
pr_debug("debug message\n");     // 需定义DEBUG
dev_dbg(dev, "device debug\n");  // 设备相关

// 断言
BUG_ON(condition);     // 条件为真时触发BUG
WARN_ON(condition);    // 条件为真时警告
```
