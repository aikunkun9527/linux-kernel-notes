# 进程状态与切换

> [!info] 目标
> 理解Linux进程状态转换和上下文切换机制

## 进程状态定义

### 状态常量

```c
// include/linux/sched.h
#define TASK_RUNNING            0x0000
#define TASK_INTERRUPTIBLE      0x0001
#define TASK_UNINTERRUPTIBLE    0x0002
#define TASK_STOPPED            0x0004
#define TASK_TRACED             0x0008

#define EXIT_ZOMBIE             0x0010
#define EXIT_DEAD               0x0020

#define TASK_PARKED             0x0040
#define TASK_DEAD               0x0080
#define TASK_WAKEKILL           0x0100
#define TASK_WAKING             0x0200
#define TASK_NOLOAD             0x0400
#define TASK_NEW                0x0800
```

### 状态详解

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| TASK_RUNNING | 运行或就绪 | 被调度执行 |
| TASK_INTERRUPTIBLE | 可中断睡眠 | 等待资源/事件 |
| TASK_UNINTERRUPTIBLE | 不可中断睡眠 | 等待硬件 |
| TASK_STOPPED | 停止 | SIGSTOP/SIGTSTP |
| TASK_TRACED | 被追踪 | ptrace |
| EXIT_ZOMBIE | 僵尸 | exit()，未被wait |
| EXIT_DEAD | 死亡 | 被父进程回收 |

## 上下文切换

### 切换时机

1. **主动切换**：进程调用 `schedule()`
2. **被动切换**：
   - 时间片用完
   - 高优先级进程就绪
   - 进程睡眠（等待资源）
   - 进程终止

### 切换流程

```
schedule()
    │
    ▼
┌─────────────────┐
│ 选择下一个进程  │
│ pick_next_task()│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 检查是否需要切换│
│ prev != next?   │
└────────┬────────┘
         │
    ┌────┴────┐
    │需要     │不需要
    ▼         │
┌─────────────────┐
│ context_switch  │
└────────┬────────┘
         │
         ├─────────────────────┐
         │                     │
         ▼                     ▼
┌─────────────────┐   ┌─────────────────┐
│ switch_mm       │   │ switch_to       │
│ (切换地址空间)  │   │ (切换栈和寄存器)│
└─────────────────┘   └─────────────────┘
```

### context_switch()

```c
// kernel/sched/core.c
static __always_inline struct rq *
context_switch(struct rq *rq, struct task_struct *prev,
               struct task_struct *next, struct rq_flags *rf)
{
    // 1. 切换地址空间
    if (!next->mm) {
        // next是内核线程
        enter_lazy_tlb(prev->active_mm, next);
        next->active_mm = prev->active_mm;
    } else {
        // next是用户进程
        switch_mm_irqs_off(prev->active_mm, next->mm, next);
    }

    // 2. 切换栈和寄存器
    switch_to(prev, next, prev);

    return finish_task_switch(prev);
}
```

### switch_to() - 架构相关

```c
// arch/x86/include/asm/switch_to.h
#define switch_to(prev, next, last)                              \
do {                                                             \
    ((last) = __switch_to_asm((prev), (next)));                  \
} while (0)

// 汇编实现
ENTRY(__switch_to_asm)
    /* 保存被调用者保存的寄存器 */
    pushq   %rbp
    pushq   %rbx
    pushq   %r12
    pushq   %r13
    pushq   %r14
    pushq   %r15

    /* 保存内核栈指针 */
    movq    %rsp, TASK_threadsp(%rdi)

    /* 切换到新进程的栈 */
    movq    TASK_threadsp(%rsi), %rsp

    /* 恢复被调用者保存的寄存器 */
    popq    %r15
    popq    %r14
    popq    %r13
    popq    %r12
    popq    %rbx
    popq    %rbp

    jmp     __switch_to
END(__switch_to_asm)
```

### switch_mm()

```c
// arch/x86/mm/tlb.c
void switch_mm_irqs_off(struct mm_struct *prev, struct mm_struct *next,
                        struct task_struct *tsk)
{
    unsigned cpu = smp_processor_id();

    // 1. 更新CR3寄存器
    if (need_flush)
        load_cr3(next->pgd);
    else
        write_cr3(__sme_pa(next->pgd));

    // 2. 刷新TLB（必要时）
    if (need_flush)
        __flush_tlb_all();

    // 3. 更新PCID（如果启用）
    // 4. 更新active_mm
    this_cpu_write(cpu_tlbstate.active_mm, next);
}
```

### 阻塞流程

```c

{
    DEFINE_WAIT(wait);

    // 1. 将当前进程加入等待队列
    prepare_to_wait(wq, &wait, TASK_INTERRUPTIBLE);

    // 2. 设置状态并调度

    finish_wait(wq, &wait);
}
```
