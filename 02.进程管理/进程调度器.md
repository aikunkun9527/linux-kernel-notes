# 进程调度器

> [!info] 目标
> 理解Linux进程调度机制与调度器实现

## 调度器概述

Linux调度器负责：
- 选择下一个运行的进程
- 公平分配CPU时间
- 支持实时调度需求

## 调度类（Scheduling Classes）

调度器采用模块化设计，支持多种调度策略：

```
优先级（高→低）
├── stop_sched_class     // CPU停止任务
├── dl_sched_class       // 截止时间调度
├── rt_sched_class       // 实时调度
├── fair_sched_class     // 完全公平调度（CFS）
└── idle_sched_class     // 空闲任务
```

### 调度策略

| 策略 | 宏 | 说明 |
|------|-----|------|
| SCHED_NORMAL | 0 | 普通进程（CFS） |
| SCHED_FIFO | 1 | 实时FIFO |
| SCHED_RR | 2 | 实时轮转 |
| SCHED_BATCH | 3 | 批处理 |
| SCHED_IDLE | 5 | 空闲进程 |
| SCHED_DEADLINE | 6 | 截止时间 |

## CFS（完全公平调度器）

### 核心概念

CFS使用**虚拟运行时间（vruntime）** 实现公平调度：

```c
// 虚拟运行时间计算
vruntime += delta_exec * (NICE_0_LOAD / se->load.weight)
```

- 优先级高的进程：vruntime增长慢
- 优先级低的进程：vruntime增长快
- 总是选择vruntime最小的进程运行

### 红黑树组织

CFS使用红黑树组织可运行进程：

```
            vruntime
               │
        ┌──────┴──────┐
        │             │
    较小vruntime   较大vruntime
    （优先运行）   （后运行）
```

### 时间切片

```c
// 调度周期
sysctl_sched_latency = 6ms  // 默认目标延迟

// 单进程时间片 = 调度周期 × (进程权重 / 总权重)
```

## 调度相关数据结构

### sched_entity

```c
struct sched_entity {
    struct load_weight load;      // 权重
    struct rb_node run_node;      // 红黑树节点
    u64 vruntime;                  // 虚拟运行时间
    u64 exec_start;                // 执行开始时间
    // ...
};
```

### 运行队列

```c
struct rq {
    unsigned int nr_running;       // 可运行进程数
    u64 clock;                     // 时钟
    struct task_struct *curr;      // 当前进程
    struct cfs_rq cfs;             // CFS运行队列
    struct rt_rq rt;               // RT运行队列
    // ...
};
```

## 进程优先级

### 优先级范围

```
实时优先级:  0 ── 99 （数值越大优先级越高）
静态优先级: 100 ── 139 （数值越小优先级越高，对应nice -20 ~ +19）
```

### nice值

```bash
# 查看进程nice值
ps -eo pid,ni,comm

# 启动时设置nice值
nice -n 10 ./program

# 修改运行进程nice值
renice -n 5 -p <pid>
```

### 优先级映射

```c
// nice值到权重的映射
static const int prio_to_weight[40] = {

```

## 调度时机

1. **主动调度**：进程调用`schedule()`
2. **抢占调度**：
   - 时钟中断
   - 唤醒高优先级进程
   - 进程状态改变

## 相关文件

```

# 查看调度参数

# 常用参数
kernel.sched_min_granularity_ns    # 最小调度粒度
kernel.sched_wakeup_granularity_ns # 唤醒粒度
kernel.sched_latency_ns            # 目标延迟
```
