# Linux内存管理

> [!info] 概述
> 内存管理是Linux内核最核心的子系统之一，负责物理内存分配、虚拟内存映射、页面缓存等功能

## 🧠 核心概念

### 地址空间层次
```
用户视角              内核视角               硬件视角
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 虚拟地址空间 │ ←→ │  页表映射   │ ←→ │  物理内存   │
│ (进程独占)  │    │  (MMU)     │    │  (共享)     │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 内存管理目标
1. **虚拟化**：每个进程拥有独立地址空间
2. **保护**：进程间内存隔离
3. **高效**：最小化内存碎片，最大化利用率
4. **抽象**：提供简单的内存分配接口

## 📊 内存布局

### 32位系统虚拟地址空间
```
0xFFFFFFFF ┌──────────────────┐
           │   内核空间        │ 1GB
0xC0000000 ├──────────────────┤
           │   用户栈          │ ↓增长
           ├──────────────────┤
           │   ...            │
           ├──────────────────┤
           │   mmap区域        │
           ├──────────────────┤
           │   ...            │
           ├──────────────────┤
           │   堆              │ ↑增长
           ├──────────────────┤
           │   BSS段           │
           ├──────────────────┤
           │   数据段          │
           ├──────────────────┤
           │   代码段          │
0x08048000 ├──────────────────┤
           │   保留区域        │
0x00000000 └──────────────────┘
```

## 🛠️ 内存分配API速查

### 内核态分配

| API | 用途 | 说明 |
|-----|------|------|
| `alloc_pages()` | 分配物理页 | 返回`struct page*` |
| `__get_free_pages()` | 分配连续页 | 返回虚拟地址 |
| `kmalloc()` | 小对象分配 | Slab分配器 |
| `vmalloc()` | 虚拟连续内存 | 可能不物理连续 |
| `kzalloc()` | 零初始化分配 | kmalloc + memset |

### 用户态映射

| 系统调用 | 用途 |
|----------|------|
| `mmap()` | 内存映射 |
| `munmap()` | 取消映射 |
| `mprotect()` | 修改保护属性 |
| `mlock()` | 锁定内存 |

## 📈 性能监控

```bash
# 查看内存信息
cat /proc/meminfo

# 进程内存映射
pmap -x <pid>

# 页表统计
cat /proc/<pid>/status | grep -i vm

# 内存区域统计
cat /proc/zoneinfo
```
