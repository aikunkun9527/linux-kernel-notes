# 内存区域与节点

> [!info] 目标
> 理解Linux内核如何组织和管理物理内存

## 内存管理模型

Linux使用**非一致内存访问（NUMA）** 模型组织内存：

```
系统内存
    │
    ├── Node 0 (CPU 0)
    │   ├── Zone DMA
    │   ├── Zone DMA32
    │   ├── Zone Normal
    │   └── Zone Movable
    │
    └── Node 1 (CPU 1)
        ├── Zone DMA
        ├── Zone DMA32
        └── Zone Normal
```

## 内存节点（Node）

### pg_data_t 结构

```c
// include/linux/mmzone.h
typedef struct pglist_data {
    struct zone node_zones[MAX_NR_ZONES];  // 该节点的内存区域
    struct zonelist node_zonelists[MAX_ZONELISTS]; // 区域列表
    int nr_zones;                          // 区域数量
    unsigned long node_start_pfn;          // 起始页帧号
    unsigned long node_present_pages;      // 总页数
    unsigned long node_spanned_pages;      // 包含空洞的总页数
    int node_id;                           // 节点ID

    wait_queue_head_t kswapd_wait;         // kswapd等待队列
    struct task_struct *kswapd;            // 页面回收守护进程

    unsigned long totalreserve_pages;      // 保留页数
    // ...
} pg_data_t;
```

### 节点访问

```c
// 获取节点
pg_data_t *NODE_DATA(int nodeid);

// UMA系统中只有一个节点
extern pg_data_t contig_page_data;
#define NODE_DATA(nid) (&contig_page_data)
```

## 内存区域（Zone）

### 区域类型

| 区域类型 | 用途 | 典型范围 |
|----------|------|----------|
| ZONE_DMA | DMA设备使用的低地址内存 | 0-16MB |
| ZONE_DMA32 | 32位DMA设备可访问内存 | 0-4GB |
| ZONE_NORMAL | 普通内存区域 | 16MB-896MB(32位) |
| ZONE_HIGHMEM | 高端内存（仅32位） | >896MB |
| ZONE_MOVABLE | 可迁移页面 | 防止碎片 |

### zone 结构体

```c
struct zone {
    /* 水位线 */
    unsigned long watermark[NR_WMARK];
    unsigned long managed_pages;    // 管理的页面数
    unsigned long present_pages;    // 实际存在的页面数

    /* 伙伴系统 */
    struct free_area free_area[MAX_ORDER];
    unsigned long flags;            // 区域标志

    /* 统计信息 */
    atomic_long_t vm_stat[NR_VM_ZONE_STAT_ITEMS];

    /* 锁 */
    spinlock_t lock;                // 保护该区域

    /* 页面回收相关 */
    unsigned long dirty;            // 脏页数
    unsigned long inactive;         // 不活跃页数
    // ...

} ____cacheline_internodealigned_in_smp;
```

### 水位线（Watermarks）

```c
enum zone_watermarks {
    WMARK_MIN,   // 最小水位线，低于此值开始回收
    WMARK_LOW,   // 低水位线，开始kswapd后台回收
    WMARK_HIGH,  // 高水位线，kswapd停止回收
    NR_WMARK
};
```

```
          ┌────────────────────┐
          │   WMARK_HIGH       │ ←─ kswapd停止
          ├────────────────────┤
          │                    │
          ├────────────────────┤
          │   WMARK_LOW        │ ←─ kswapd启动
          ├────────────────────┤
          │                    │
          ├────────────────────┤
          │   WMARK_MIN        │ ←─ 直接回收
          └────────────────────┘
```

## 页帧（Page Frame）

### page 结构体

```c
// include/linux/mm_types.h
struct page {
    unsigned long flags;        // 页面标志位

    /* 联合体：根据页面用途不同 */
    union {
        struct {    /* 页缓存 */
            struct list_head lru;
            struct address_space *mapping;
            pgoff_t index;
            unsigned long private;
        };

        struct {    /* Slab */
            void *freelist;
            union {
                struct kmem_cache *slab_cache;
                struct {
                    unsigned inuse:16;
                    unsigned objects:15;
                    unsigned frozen:1;
                };
            };
        };

        struct {    /* 页表 */
            unsigned long _pt_pad_1;
            pgtable_t pmd_huge_pte;
            unsigned long _pt_pad_2;
            union {
                struct mm_struct *pt_mm;
                atomic_t pt_frag_refcount;
            };
        };

        struct {    /* 伙伴系统 */
            unsigned long _pad_1;
            unsigned long _pad_2;
        };
    };

    /* 引用计数 */
    atomic_t _refcount;

    /* 映射计数（反向映射） */
    atomic_t _mapcount;

    // ...
};
```

### 页面标志位

```c
// include/linux/page-flags.h
enum pageflags {
    PG_locked,        // 页面被锁定
    PG_referenced,    // 最近被访问
    PG_uptodate,      // 数据有效
    PG_dirty,         // 页面被修改
    PG_lru,           // 在LRU链表中
    PG_active,        // 在活跃链表
    PG_workingset,    // 工作集页面
    PG_waiters,       // 有等待者
    PG_error,         // I/O错误
    PG_slab,          // Slab页面
    PG_owner_priv_1,  // 所有者私有
    PG_arch_1,        // 架构相关
    PG_reserved,      // 保留页面
    PG_private,       // 私有数据
    PG_private_2,     // 私有标志2
    PG_writeback,     // 正在写回
    PG_head,          // 复合页头部
    PG_mappedtodisk,  // 已映射到磁盘
    PG_reclaim,       // 将被回收
    PG_swapbacked,    // 有swap支持
    PG_unevictable,   // 不可回收
    // ...
};
```

## 内存模型

Linux支持三种内存模型：

### 1. FLATMEM（平坦内存）
```
适用于UMA系统
所有物理内存连续编址
mem_map[] 数组存储所有page结构
```

### 2. DISCONTIGMEM（不连续内存）
```
适用于NUMA系统早期
每个节点有自己的mem_map
```

### 3. SPARSEMEM（稀疏内存）
```
当前主流模型
支持内存热插拔
按section组织，节省内存
```

## 查看系统内存布局

```bash
# 查看内存区域信息
cat /proc/zoneinfo

# 查看NUMA节点信息
numactl --hardware

# 查看物理内存布局
cat /proc/iomem | grep -i memory
```
