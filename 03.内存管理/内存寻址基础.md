# 内存寻址基础

> [!info] 目标
> 理解x86架构下的内存寻址机制

## 三种地址概念

### 1. 逻辑地址（Logical Address）
- 段选择子 + 偏移量
- 程序中直接使用的地址

### 2. 线性地址（Linear Address）
- 虚拟地址空间中的地址
- 32位：0x00000000 ~ 0xFFFFFFFF

### 3. 物理地址（Physical Address）
- 内存芯片上的实际地址
- 由内存控制器使用

## 地址转换过程

```
逻辑地址                    线性地址                    物理地址
(段选择子:偏移)    分段      (虚拟地址)     分页        (实际)
       │          单元          │          单元          │
       │    ┌──────────────┐    │    ┌──────────────┐    │
       └───►│  段描述符     │───►└───►│   页表       │───►┘
            │  GDTR/LDTR   │         │   CR3        │
            └──────────────┘         └──────────────┘
```

## 分段机制

### 段选择子

```
┌─────────┬───┬───┐
│  Index  │TI │RPL│
│ (13bit) │1b │2b │
└─────────┴───┴───┘
```
- Index：段描述符索引
- TI：0=GDT，1=LDT
- RPL：请求特权级

### 段描述符

```
 31                16 15  14  13 12  11   8 7     5 4                0
┌───────────────────┬─────┬───┬───┬────────┬───────┬─────────────────┐
│    Base [31:24]   │ G │ D │   │   │ Limit  │       │  Base [23:16]   │
│                   │   │ B │   │   │[19:16] │       │                 │
├───────────────────┴─────┴───┴───┴────────┴───────┴─────────────────┤
│                          Base [15:0]                                │
├─────────────────────────────────────────────────────────────────────┤
│                         Limit [15:0]                                │
└─────────────────────────────────────────────────────────────────────┘
```

### Linux分段处理

Linux在x86上**最小化使用分段**：

```c
// 所有段基址都设为0
#define __KERNEL_CS   0x10  // 内核代码段
#define __KERNEL_DS   0x18  // 内核数据段
#define __USER_CS     0x23  // 用户代码段
#define __USER_DS     0x2B  // 用户数据段

// 实际逻辑地址 = 线性地址
```

## 分页机制

### 页表层级

**32位系统（2级页表）**：
```
线性地址 (32bit)
┌─────────┬─────────┬──────────┐
│ 页目录   │ 页表     │ 页内偏移   │
│ (10bit) │ (10bit) │ (12bit)  │
└─────────┴─────────┴──────────┘
```

**64位系统（4级页表）**：
```
线性地址 (48bit)
┌────────┬────────┬────────┬────────┬──────────┐
│ PML4   │ PDPT   │ PD     │ PT     │ Offset   │
│(9bit)  │(9bit)  │(9bit)  │(9bit)  │(12bit)   │
└────────┴────────┴────────┴────────┴──────────┘
```

### 页表项

```c
// 页表项结构
struct pte {
    unsigned long present:1;     // 存在位
    unsigned long rw:1;          // 读/写
    unsigned long user:1;        // 用户/内核
    unsigned long pwt:1;         // 写穿透
    unsigned long pcd:1;         // 禁用缓存
    unsigned long accessed:1;    // 已访问
    unsigned long dirty:1;       // 已修改
    unsigned long pse:1;         // 大页
    unsigned long global:1;      // 全局页
    unsigned long available:3;   // 可用位
    unsigned long pfn:20;        // 物理页帧号
};
```

### CR3寄存器

CR3存储当前进程的页目录基地址：

```asm
; 切换进程时更新CR3
mov eax, [task->mm->pgd]
mov cr3, eax
```

## TLB（Translation Lookaside Buffer）

### TLB作用
- 缓存虚拟地址到物理地址的映射
- 加速地址转换

### TLB刷新

```c
// 刷新整个TLB
static inline void __flush_tlb(void) {
    write_cr3(read_cr3());
}

// 刷新单个页
static inline void __flush_tlb_one(unsigned long addr) {
    __asm__ __volatile__("invlpg (%0)" : : "r" (addr));
}
```

## 大页支持

### Huge Pages

```bash
# 查看大页信息
cat /proc/meminfo | grep Huge

# 大页大小
Hugepagesize: 2048 kB  # 2MB大页
```

### 优点
- 减少页表层级
- 降低TLB缺失率
- 提高内存访问效率
