# 内存映射

> [!info] 目标
> 理解Linux内存映射（mmap）机制的实现原理

## mmap概述

mmap（内存映射）将文件或设备映射到进程地址空间：
- 文件内容可以直接通过内存访问
- 避免用户态和内核态之间的数据拷贝
- 支持进程间共享内存

## mmap系统调用

### 用户态接口

```c
#include <sys/mman.h>

void *mmap(void *addr, size_t length, int prot, int flags,
           int fd, off_t offset);

int munmap(void *addr, size_t length);

// 参数说明：
// addr:   建议的映射地址（通常为NULL）
// length: 映射长度
// prot:   访问权限 (PROT_READ, PROT_WRITE, PROT_EXEC)
// flags:  映射类型 (MAP_SHARED, MAP_PRIVATE, MAP_ANONYMOUS)
// fd:     文件描述符（匿名映射时为-1）
// offset: 文件偏移
```

### 权限标志

```c
PROT_READ   // 可读
PROT_WRITE  // 可写
PROT_EXEC   // 可执行
PROT_NONE   // 不可访问
```

### 映射类型

```c
MAP_SHARED        // 共享映射，修改会写回文件
MAP_PRIVATE       // 私有映射，写时复制
MAP_ANONYMOUS     // 匿名映射，不关联文件
MAP_FIXED         // 强制使用指定地址
MAP_LOCKED        // 锁定映射区域
MAP_POPULATE      // 预分配页面
MAP_HUGETLB       // 使用大页
```

## 内核实现

### vm_operations_struct

```c
struct vm_operations_struct {
    void (*open)(struct vm_area_struct *area);
    void (*close)(struct vm_area_struct *area);

    // 处理缺页
    vm_fault_t (*fault)(struct vm_fault *vmf);

    // 大页缺页
    vm_fault_t (*huge_fault)(struct vm_fault *vmf, unsigned int order);

    // 页面写保护
    void (*map_pages)(struct vm_fault *vmf,
                      pgoff_t start_pgoff, pgoff_t end_pgoff);

    // 页面可写通知
    void (*page_mkwrite)(struct vm_fault *vmf);

    // 访问权限改变
    int (*access)(struct vm_area_struct *vma, unsigned long addr,
                  void *buf, int len, int write);
};
```

### 文件映射的vm_ops

```c
// mm/filemap.c
static const struct vm_operations_struct generic_file_vm_ops = {
    .fault = filemap_fault,
    .map_pages = filemap_map_pages,
    .page_mkwrite = filemap_page_mkwrite,
};
```

### 匿名映射的vm_ops

```c

static const struct vm_operations_struct anonymous_vm_ops = {
```

## 共享内存

### POSIX共享内存

```c
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>

// 创建共享内存对象
int fd = shm_open("/myshm", O_CREAT | O_RDWR, 0666);
ftruncate(fd, 4096);

// 映射共享内存
void *ptr = mmap(NULL, 4096, PROT_READ | PROT_WRITE,
                 MAP_SHARED, fd, 0);

// 使用共享内存
strcpy(ptr, "Hello, shared memory!");

// 清理
munmap(ptr, 4096);
shm_unlink("/myshm");
```

### System V共享内存

```c
#include <sys/shm.h>

// 创建共享内存
int shmid = shmget(IPC_PRIVATE, 4096, IPC_CREAT | 0666);

// 附加共享内存
void *ptr = shmat(shmid, NULL, 0);

// 分离
shmdt(ptr);

// 删除
shmctl(shmid, IPC_RMID, NULL);
```

## 使用示例

### 映射文件

```c
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>

int fd = open("file.txt", O_RDWR);
struct stat sb;
fstat(fd, &sb);

void *addr = mmap(NULL, sb.st_size,
                  PROT_READ | PROT_WRITE,
                  MAP_SHARED, fd, 0);

// 修改文件内容
memcpy(addr, "Hello", 5);

// 同步到磁盘
msync(addr, sb.st_size, MS_SYNC);

munmap(addr, sb.st_size);
close(fd);
```

### 匿名映射

```c
// 私有匿名映射（类似malloc）
void *addr = mmap(NULL, 4096,
                  PROT_READ | PROT_WRITE,
                  MAP_PRIVATE | MAP_ANONYMOUS,
                  -1, 0);

munmap(addr, 4096);

// 共享匿名映射（父子进程共享）
void *shared = mmap(NULL, 4096,
                    PROT_READ | PROT_WRITE,
                    MAP_SHARED | MAP_ANONYMOUS,
                    -1, 0);

if (fork() == 0) {
    // 子进程
    strcpy(shared, "Hello from child");
} else {
    // 父进程
    wait(NULL);
    printf("Parent got: %s\n", (char*)shared);
}
munmap(shared, 4096);
```
