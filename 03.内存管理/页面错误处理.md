# 页面错误处理

> [!info] 目标
> 理解Linux缺页中断的处理流程

## 页面错误概述

页面错误（Page Fault）是CPU在访问内存时产生的异常：
- 页面不在物理内存中
- 访问权限不足
- 写只读页面

## 页面错误类型

| 错误码位 | 含义 |
|----------|------|
| bit 0 (P) | 0=页面不存在，1=保护错误 |
| bit 1 (W/R) | 0=读操作，1=写操作 |
| bit 2 (U/S) | 0=内核态，1=用户态 |
| bit 3 (RSVD) | 保留位错误 |
| bit 4 (I/D) | 0=数据，1=指令获取 |

## 核心函数

### do_page_fault

```c
// arch/x86/mm/fault.c
static noinline void
__do_page_fault(struct pt_regs *regs, unsigned long hw_error_code,
                unsigned long address)
{
    struct vm_area_struct *vma;
    struct task_struct *tsk = current;
    struct mm_struct *mm = tsk->mm;

    // 1. 检查是否在中断上下文
    if (unlikely(fault_in_kernel_space(address))) {
        // 内核空间缺页
        vmalloc_fault(address);
        return;
    }

    // 2. 查找VMA
    vma = find_vma(mm, address);
    if (!vma || address < vma->vm_start) {
        // 栈扩展？
        if (!(vma && expand_stack(vma, address)))
            bad_area_nosemaphore(regs, hw_error_code, address);
        return;
    }

    // 3. 检查权限
    if (hw_error_code & X86_PF_WRITE) {
        if (!(vma->vm_flags & VM_WRITE))
            bad_area_access_error(regs, hw_error_code, address);
    }

    // 4. 处理缺页
    handle_mm_fault(vma, address, flags);
}
```

### handle_mm_fault

```c
// mm/memory.c
vm_fault_t handle_mm_fault(struct vm_area_struct *vma,
                           unsigned long address, unsigned int flags)
{
    vm_fault_t ret;

    // 获取或创建页表项
    pgd = pgd_offset(mm, address);
    p4d = p4d_alloc(mm, pgd, address);
    pud = pud_alloc(mm, p4d, address);
    pmd = pmd_alloc(mm, pud, address);
    pte = pte_alloc_map(mm, pmd, address);

    // 调用VMA的fault处理
    if (vma->vm_ops && vma->vm_ops->fault) {
        ret = vma->vm_ops->fault(vmf);
    }

    return ret;
}
```

## 匿名页面缺页

```c
// mm/memory.c
static vm_fault_t do_anonymous_page(struct vm_fault *vmf)
{
    struct page *page;

    // 1. 分配新页面
    page = alloc_zeroed_user_highpage_movable(vma, vmf->address);

    // 2. 建立页表映射
    set_pte_at(mm, vmf->address, vmf->pte, pte);

    // 3. 加入LRU链表
    lru_cache_add_active_or_unevictable(page, vma);

    return 0;
}
```

## 文件映射缺页

```c
// mm/filemap.c
vm_fault_t filemap_fault(struct vm_fault *vmf)
{
    struct file *file = vmf->vma->vm_file;
    struct address_space *mapping = file->f_mapping;
    struct page *page;

    // 1. 查找页缓存
    page = find_get_page(mapping, offset);

    // 2. 页面不在缓存中，需要读取
    if (!page) {
        page = page_cache_alloc(mapping);
        add_to_page_cache_lru(page, mapping, offset, gfp);
        mapping->a_ops->readpage(file, page);
    }

    // 3. 页面已在缓存，直接使用
    vmf->page = page;
    return 0;
}
```

## 写时复制（COW）

```c
// 写时复制处理
static vm_fault_t do_wp_page(struct vm_fault *vmf)
{
    struct page *old_page = vmf->page;

    // 1. 检查是否可以复用
    if (page_count(old_page) == 1) {
        // 只有一个使用者，直接改为可写
        pte_unshare(vmf);
        return 0;
    }

    // 2. 多个使用者，需要复制
    new_page = alloc_page_vma(GFP_HIGHUSER, vma, vmf->address);
    copy_user_highpage(new_page, old_page, vmf->address, vma);

    // 3. 替换页表项
    pte_clear(vmf->pte);
    set_pte_at(mm, vmf->address, vmf->pte,
               pte_mkwrite(pte_mkdirty(mk_pte(new_page, vma->vm_page_prot))));

    // 4. 减少原页面引用
    page_remove_rmap(old_page, vma);

    return VM_FAULT_WRITE;
}
```

## 缺页类型总结

| 场景 | 处理方式 |
|------|----------|
| 页面不存在（匿名） | 分配新页面，填零 |
| 页面不存在（文件） | 从文件读取到页缓存 |
| 写只读页面（COW） | 复制页面，更新页表 |
| 写只读页面（真实只读） | 发送SIGSEGV |
| 访问内核空间 | 检查vmalloc等 |
| 访问无效地址 | 发送SIGSEGV |
| 栈溢出 | 尝试扩展栈 |
