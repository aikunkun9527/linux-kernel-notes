# Linux中断与异常

> [!info] 概述
> 中断和异常是CPU响应外部事件和错误情况的机制，是操作系统实现异步处理和系统调用的基础

## 🧠 核心概念

### 中断 vs 异常

| 特性 | 中断（Interrupt） | 异常（Exception） |
|------|------------------|------------------|
| 来源 | 外部设备/CPU | 程序执行 |
| 触发时机 | 异步 | 同步 |
| 处理后 | 返回下条指令 | 可能返回当前指令 |
| 示例 | 键盘、时钟 | 除零、缺页 |

### 中断分类

```
中断
├── 硬件中断（外部）
│   ├── 可屏蔽中断（INTR）
│   │   ├── 定时器中断
│   │   ├── 键盘中断
│   │   ├── 磁盘中断
│   │   └── 网卡中断
│   └── 不可屏蔽中断（NMI）
│       └── 硬件故障
│
├── 软件中断
│   ├── int指令（系统调用）
│   └── 软中断（kernel softirq）
│
└── 异常（内部）
    ├── 故障（Fault）
    │   ├── 缺页异常
    │   ├── 段不存在
    │   └── 栈段故障
    ├── 陷阱（Trap）
    │   ├── 断点（int3）
    │   └── 系统调用
    └── 终止（Abort）
        ├── 双重故障
        └── 机器检查
```

## IDT（中断描述符表）

### 结构

```
IDT: 256个描述符（32位：256个，64位：256个）

向量号  用途
─────────────────────────────
0-19    CPU异常
  0     #DE 除法错误
  1     #DB 调试异常
  2     NMI 不可屏蔽中断
  3     #BP 断点
  4     #OF 溢出
  5     #BR BOUND范围越界
  6     #UD 无效操作码
  7     #NM 设备不可用
  8     #DF 双重故障
  10    #TS 无效TSS
  11    #NP 段不存在
  12    #SS 栈段故障
  13    #GP 一般保护
  14    #PF 缺页异常
  ...
20-31   Intel保留
─────────────────────────────
32-255  用户定义中断
  32    时钟中断
  33    键盘中断
  ...
  128   系统调用(0x80)
```

### 门描述符类型

| 类型 | 说明 |
|------|------|
| 中断门（Interrupt Gate） | 中断处理，自动禁用中断 |
| 陷阱门（Trap Gate） | 系统调用，不禁用中断 |
| 任务门（Task Gate） | 任务切换（很少使用） |

## 中断上下文

```c
// 中断发生时保存的栈帧
struct pt_regs {
    unsigned long r15, r14, r13, r12;
    unsigned long rbp, rbx, r11, r10;
    unsigned long r9, r8, rax, rcx;
    unsigned long rdx, rsi, rdi;
    unsigned long orig_rax;
    unsigned long rip;
    unsigned long cs;
    unsigned long eflags;
    unsigned long rsp;      // 用户态栈指针
    unsigned long ss;
};
```

## 中断处理限制

> [!warning] 中断上下文限制
> 在中断上下文中**不能**：
> - 睡眠或阻塞（不能调用schedule、kmalloc睡眠模式）
> - 访问用户空间地址
> - 持有需要睡眠的锁
> - 执行耗时的操作
>
> 原因：中断不属于任何进程，无法被调度

## 下半部机制对比

| 机制 | 执行上下文 | 可睡眠 | 并发 | 适用场景 |
|------|-----------|--------|------|----------|
| 软中断 | 中断上下文 | 否 | 多CPU并行 | 高性能网络 |
| Tasklet | 中断上下文 | 否 | 同类型串行 | 一般设备 |
| 工作队列 | 进程上下文 | 是 | 并行 | 耗时操作 |

## 中断注册API

```c
#include <linux/interrupt.h>

// 注册中断处理程序
int request_irq(unsigned int irq,
                irq_handler_t handler,
                unsigned long flags,
                const char *name,
                void *dev);

// 标志位
IRQF_SHARED     // 共享中断线
IRQF_TRIGGER_RISING   // 上升沿触发
IRQF_TRIGGER_FALLING  // 下降沿触发
IRQF_TRIGGER_HIGH     // 高电平触发
IRQF_TRIGGER_LOW      // 低电平触发

// 返回值
IRQ_HANDLED     // 中断已处理
IRQ_WAKE_THREAD // 唤醒线程处理

// 释放
void free_irq(unsigned int irq, void *dev);
```

## 常用查看命令

```bash
# 查看中断统计
cat /proc/interrupts

# 查看软中断统计
cat /proc/softirqs

# 实时监控中断
watch -n 1 cat /proc/interrupts

# 查看特定IRQ的亲和性
cat /proc/irq/<irq>/smp_affinity
```
