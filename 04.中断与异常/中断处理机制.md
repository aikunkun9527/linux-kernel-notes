# 中断处理机制

> [!info] 目标
> 理解Linux内核的中断处理框架

## 中断分类

### 硬件中断
- **外部中断**：来自外部设备
- **内部中断**：CPU内部产生（如除零）

### 软件中断
- `int`指令触发
- 系统调用入口

## 中断处理流程

```
硬件中断请求
      │
      ▼
┌──────────────┐
│  中断控制器   │ (PIC/APIC)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   CPU响应    │ 保存CS:EIP, EFLAGS
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  IDT查表     │ 获取中断向量号
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 中断处理程序  │ ISR (Interrupt Service Routine)
└──────────────┘
```

## IDT（中断描述符表）

### 结构

```c
// IDT描述符
struct idt_desc {
    u16 offset_low;    // 偏移量低16位
    u16 segment;       // 段选择子
    u16 reserved;      // 保留
    u16 flags;         // 属性
    u16 offset_high;   // 偏移量高16位
} __attribute__((packed));
```

### 中断向量分配

| 向量范围 | 用途 |
|----------|------|
| 0-19 | CPU异常 |
| 20-31 | Intel保留 |
| 32-127 | 外部中断 |
| 128 | 系统调用(0x80) |
| 129-239 | 外部中断(扩展) |
| 240-255 | 本地APIC |

## 中断门描述符

```c
// 中断门
struct gate_struct {
    u16 offset_low;
    u16 segment;
    unsigned ist : 3;    // IST索引
    unsigned zero : 5;
    unsigned type : 5;   // 类型
    unsigned dpl : 2;    // 描述符特权级
    unsigned p : 1;      // 存在位
    u16 offset_middle;
    u32 offset_high;
    u32 reserved;
};
```

## 中断上下文

```c
// 中断栈帧
struct pt_regs {
    unsigned long r15, r14, r13, r12;
    unsigned long rbp, rbx, r11, r10;
    unsigned long r9, r8, rax, rcx;
    unsigned long rdx, rsi, rdi;
    unsigned long orig_rax;
    unsigned long rip;
    unsigned long cs;
    unsigned long eflags;
    unsigned long rsp;
    unsigned long ss;
};
```

## 中断处理程序

### 注册中断处理

```c
#include <linux/interrupt.h>

// 中断处理函数
irqreturn_t my_handler(int irq, void *dev_id) {
    // 处理中断
    return IRQ_HANDLED;
}

// 注册中断
int request_irq(unsigned int irq, irq_handler_t handler,
                unsigned long flags, const char *name, void *dev);

// 示例
request_irq(IRQ_NUM, my_handler, IRQF_SHARED, "mydev", &my_dev);
```

### 释放中断

```c
void free_irq(unsigned int irq, void *dev_id);
```

## 中断处理限制

> [!warning] 注意
> 在中断上下文中：
> - **不能睡眠**（不能调用schedule、kmalloc等）
> - **不能访问用户空间**
> - **执行时间应尽量短**

## 中断下半部

为了快速响应中断，将处理分为：

### 1. 上半部（Top Half）
- 真正的中断处理程序
- 快速完成必要操作
- 触发下半部处理

### 2. 下半部（Bottom Half）
- 延后执行
- 可睡眠
- 处理耗时操作
