# 系统调用机制

> 理解Linux系统调用的实现原理

> [!note] 系统调用完整笔记

## 系统调用概述

系统调用是用户程序请求内核服务的接口：
- 用户态 → 内核态的入口
- 提供安全的硬件访问
- 统一的服务接口

## 系统调用流程

```
用户程序                    内核
   │                        │
   │ 调用库函数              │
   │ (如write())            │
   ▼                        │
┌─────────┐                 │
│ libc    │                 │
│ wrapper │                 │
└────┬────┘                 │
     │ 系统调用号→eax       │
     │ sysenter/int 0x80    │
     ▼                      │
┌─────────┐                 │
│ CPU切换  │                 │
│ 特权级   │─────────────────►
└─────────┘                 │
                     ┌──────┴──────┐
                     │ 系统调用入口 │
                     │ entry_SYSCALL│
                     └──────┬──────┘
                            │
                     ┌──────▼──────┐
                     │sys_call_table│
                     └──────┬──────┘
                            │
                     ┌──────▼──────┐
                     │ sys_xxx()   │
                     └──────┬──────┘
                            │
                     ┌──────▼──────┐
                     │ iret/sysret │
                     └──────┬──────┘
                            │
   ◄────────────────────────┘
```

## 系统调用入口

### x86_64 (syscall指令)

```asm
; 用户态
mov rax, __NR_write    ; 系统调用号
mov rdi, fd            ; 参数1
mov rsi, buf           ; 参数2
mov rdx, count         ; 参数3
syscall                ; 进入内核

; 内核入口 (entry_SYSCALL_64)
swapgs                 ; 切换GS
mov rsp, gs:kernel_rsp ; 切换栈
push rcx               ; 保存返回地址
push r11               ; 保存RFLAGS
...
call sys_call_table[rax*8]
...
sysretq                ; 返回用户态
```

### 传统方式 (int 0x80)

```asm
mov eax, __NR_write
int 0x80
; 返回值在eax中
```

## 系统调用表

```c
// arch/x86/entry/syscalls/syscall_64.tbl
0   common  read            sys_read
1   common  write           sys_write
2   common  open            sys_open
3   common  close           sys_close
...

// 内核中的系统调用表
extern const sys_call_ptr_t sys_call_table[];
```

## 添加新系统调用

### 1. 定义系统调用号

```c
// include/uapi/asm-generic/unistd.h
#define __NR_mysyscall  __NR_arch_specific_syscall
__SYSCALL(__NR_mysyscall, sys_mysyscall)
```

### 2. 实现系统调用

```c
// kernel/sys.c 或新文件
SYSCALL_DEFINE2(mysyscall, int, arg1, char __user *, arg2)
{
    // 参数检查
    if (arg1 < 0)
        return -EINVAL;

    // 处理逻辑
    pr_info("mysyscall called: %d\n", arg1);

    return 0;
}
```

### 3. 注册到系统调用表

```c
// arch/x86/entry/syscalls/syscall_64.tbl
xxx common  mysyscall   sys_mysyscall
```

## 参数传递

### x86_64寄存器约定

| 参数 | 寄存器 |
|------|--------|
| 系统调用号 | rax |
| 参数1 | rdi |
| 参数2 | rsi |
| 参数3 | rdx |
| 参数4 | r10 |
| 参数5 | r8 |
| 参数6 | r9 |
| 返回值 | rax |

## 用户空间访问

```c
// 安全地从用户空间复制数据
#include <linux/uaccess.h>

// 复制到内核
if (copy_from_user(kbuf, ubuf, size))
    return -EFAULT;

// 复制到用户
if (copy_to_user(ubuf, kbuf, size))
    return -EFAULT;

// 检查指针有效性
if (!access_ok(buf, size))
    return -EFAULT;
```
