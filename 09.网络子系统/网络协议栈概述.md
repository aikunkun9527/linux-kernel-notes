## 核心数据结构

### 1. sk_buff（Socket Buffer）

```c
struct sk_buff {
    // 链表管理
    struct sk_buff      *next, *prev;

    // 时间戳
    ktime_t             tstamp;

    // 网络设备
    struct net_device   *dev;

    // 协议头指针
    unsigned char       *head;      // 缓冲区起始
    unsigned char       *data;      // 数据起始
    unsigned char       *tail;      // 数据结束
    unsigned char       *end;       // 缓冲区结束

    // 协议信息
    __be16              protocol;   // 协议类型
    __u16               transport_header; // 传输层头
    __u16               network_header;   // 网络层头
    __u16               mac_header;       // MAC层头

    // ...
};
```

### 2. net_device

```c
struct net_device {
    char            name[IFNAMSIZ];    // 接口名
    unsigned int    ifindex;           // 接口索引
    unsigned int    flags;             // 接口标志
    unsigned int    mtu;               // 最大传输单元
    unsigned char   dev_addr[MAX_ADDR_LEN]; // MAC地址

    // 操作函数
    const struct net_device_ops *netdev_ops;

    // 统计信息
    struct net_device_stats stats;

    // ...
};
```

### 3. sock

```c
struct sock {
    struct proto        *sk_prot;       // 协议操作
    struct socket       *sk_socket;     // 关联的socket
    int                 sk_state;       // 状态
    unsigned long       sk_flags;
    // ...
};
```

## 数据包收发流程

```
网卡接收数据包

       ▼
┌──────────────┐

└──────┬───────┘

       ▼
┌──────────────┐
│ NAPI轮询     │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ alloc_skb()  │ 分配sk_buff
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ eth_type_trans│ 确定协议
└──────┬───────┘
       │
       ▼

│ netif_rx()   │ 传递给协议栈
└──────┬───────┘
       │
       ▼

```

## NAPI机制

NAPI（New API）提高网络性能：

```c
// 轮询函数
int my_poll(struct napi_struct *napi, int budget);

// 初始化
void napi_enable(struct napi_struct *napi);

// 调度轮询
void napi_schedule(struct napi_struct *napi);

// 完成轮询
void napi_complete(struct napi_struct *napi);
```

## 关键源文件

```
net/
├── socket.c        # Socket核心
├── core/
│   ├── dev.c       # 设备核心

    └── eth.c       # 以太网处理
```
