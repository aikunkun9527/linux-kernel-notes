```

├── exp1_memory_layout/       # 实验一：内存布局分析
├── exp2_process_maps/        # 实验二：进程地址空间
├── exp3_page_fault_exp/      # 实验三：页面错误
├── exp4_buddy_system/        # 实验四：伙伴系统
├── exp5_slab/                # 实验五：Slab分配器
├── exp6_reclaim/             # 实验六：内存回收
└── exp7_cow/                 # 实验七：写时复制
```

## 📖 学习路线

推荐学习顺序：

```
基础准备 → 内核概述 → 进程管理 → 内存管理 → 中断异常
    ↓
系统调用 → 同步机制 → 文件系统 → 设备驱动 → 网络子系统
```

详细路线参考：[Linux内核学习路线](./Linux内核学习路线.md)
