## 实验一：系统内存布局观察

### 观察结果

#### 1.1 物理内存布局

通过 `/proc/meminfo` 查看系统内存信息：

| 指标 | 值 | 说明 |
|------|-----|------|
| MemTotal | ~4 GB | 物理内存总量 |
| MemFree | ~200-500 MB | 空闲内存 |
| MemAvailable | ~2 GB | 可用内存（含可回收） |
| Buffers | ~50-100 MB | 块设备缓冲 |
| Cached | ~1-2 GB | 页缓存 |

#### 1.2 Zone划分

Linux将物理内存划分为多个Zone：

| Zone | 范围 | 用途 |
|------|------|------|
| DMA | 0-16 MB | ISA设备DMA |
| DMA32 | 0-4 GB | 32位DMA设备 |
| Normal | >4 GB | 普通内存区域 |
| Movable | 可迁移页 | 内存热插拔支持 |

#### 1.3 水位线机制

每个Zone有三个水位线：

```
high ──────────── kswapd停止回收
low  ──────────── kswapd开始后台回收
min  ──────────── 触发直接回收（阻塞分配）
```

**水位线计算公式：**
```
min = zone_managed_pages * min_free_kbytes / 1024
low = min * 5 / 4
high = min * 3 / 2
```

#### 1.4 NUMA架构

现代服务器多为NUMA架构，每个NUMA节点有本地内存：
- 访问本地节点内存更快
- 访问远端节点内存需要跨节点互联

### 思考题

1. **为什么需要Zone划分？**
   - 硬件限制：DMA只能访问低地址内存
   - 32位兼容：DMA32支持32位设备
   - 性能优化：不同用途的内存分开管理

2. **MemFree和MemAvailable的区别？**
   - MemFree: 完全空闲的内存
   - MemAvailable: 包含可快速回收的缓存
