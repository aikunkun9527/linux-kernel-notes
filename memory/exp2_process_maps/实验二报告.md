## 实验二：进程地址空间分析

### 观察结果

#### 2.1 进程内存映射

通过 `/proc/self/maps` 查看进程的内存布局：

```
地址范围              权限  共享  偏移      设备      路径
00400000-00401000    r-xp  私有  00000000  fd:01    /path/to/exe
00600000-00601000    r--p  私有  00000000  fd:01    /path/to/exe
00601000-00602000    rw-p  私有  00001000  fd:01    /path/to/exe
...
```

#### 2.2 进程地址空间布局

```
高地址
┌─────────────────────┐ 内核空间 (用户不可访问)
├─────────────────────┤
│      栈 (Stack)     │ ← 向下增长
│          ↓          │
├─────────────────────┤
│                     │
│   内存映射区域       │ ← mmap、共享库
│                     │
├─────────────────────┤
│          ↑          │
│      堆 (Heap)      │ ← 向上增长 (malloc)
├─────────────────────┤
│   BSS段 (未初始化)   │
├─────────────────────┤
│   数据段 (Data)     │
├─────────────────────┤
│   代码段 (Text)     │
└─────────────────────┘ 低地址
```

#### 2.3 VMA（虚拟内存区域）

每个VMA代表一段连续的虚拟地址空间：
- 代码段、数据段、堆、栈
- 共享库映射
- mmap创建的映射

#### 2.4 内存分配方式比较

| 方式 | 分配位置 | 特点 |
|------|---------|------|
| malloc | 堆 | 可调整大小，需要手动释放 |
| mmap匿名 | 映射区 | 独立VMA，可设置保护属性 |
| mmap文件 | 映射区 | 与文件关联，可共享 |
| 栈 | 栈区 | 自动管理，函数局部变量 |

### 思考题

1. **为什么堆和栈的增长方向相反？**
   - 最大化两者之间的可用空间
   - 避免相互覆盖

2. **MAP_PRIVATE和MAP_SHARED的区别？**
   - PRIVATE: 写时复制，修改不影响其他进程
   - SHARED: 修改对所有映射该区域的进程可见
