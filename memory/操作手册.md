# Linux内存管理实验操作手册

## 实验环境

```bash
# 安装必要工具
sudo apt install build-essential linux-headers-$(uname -r)
sudo apt install numactl hwloc python3-matplotlib

# 创建实验目录
cd ~/kernel-lab/memory
```

---

## 实验一：系统内存布局观察

### 进入目录
```bash
cd ~/kernel-lab/memory/exp1_memory_layout
```

### 运行实验
```bash
# 查看物理内存布局
./exp1_memory_layout.sh

# 分析Zone水位线
./exp1_watermark_analyze.sh
```

### 关键命令
| 命令 | 说明 |
|------|------|
| `cat /proc/meminfo` | 查看内存信息 |
| `cat /proc/zoneinfo` | 查看Zone详情 |
| `cat /proc/buddyinfo` | 查看伙伴系统状态 |
| `numactl --hardware` | 查看NUMA拓扑 |

## 实验二：进程地址空间分析

### 进入目录
```bash
cd ~/kernel-lab/memory/exp2_process_maps
```

### 运行实验
```bash
# 分析进程内存映射
./exp2_process_maps

# 分析指定进程的VMA
python3 exp2_vma_analyzer.py $$        # 当前shell
python3 exp2_vma_analyzer.py 1         # init进程
```

### 关键命令
| 命令 | 说明 |
|------|------|
| `cat /proc/self/maps` | 查看当前进程内存映射 |
| `cat /proc/self/status` | 查看进程状态和内存 |
| `pmap $$` | 查看进程内存布局 |

## 实验三：缺页中断追踪

### 进入目录
```bash
cd ~/kernel-lab/memory/exp3_page_fault_exp
```

### 运行实验
```bash
# 编译并运行
./exp3_page_fault

# 监控缺页统计
./exp3_page_fault_monitor.sh

# 使用perf追踪（需要权限）
```

### 关键命令
| 命令 | 说明 |
|------|------|
| `grep pgfault /proc/vmstat` | 查看系统缺页统计 |
| `getrusage()` | 获取进程缺页次数 |

## 实验五：Slab分配器分析

### 进入目录
```bash
cd ~/kernel-lab/memory/exp5_slab
```

### 运行实验
```bash
# 查看Slab信息
sudo ./exp5_slab_info.sh

# 加载内核模块
cd exp5_slab_module
make
sudo insmod slab_stat.ko

# 查看自定义缓存
sudo cat /proc/slabinfo | grep my_test
cat /proc/my_slab_stat

# 卸载模块
sudo rmmod slab_stat
```

### 关键命令
| 命令 | 说明 |
|------|------|
| `sudo cat /proc/slabinfo` | 查看slab缓存信息 |
| `ls /sys/kernel/slab/` | 查看slab缓存目录 |
| `slabtop` | 实时slab监控 |

## 快速参考

### 所有实验目录结构
```
~/kernel-lab/memory/
├── exp1_memory_layout/     # 实验一：内存布局
├── exp2_process_maps/      # 实验二：进程地址空间
├── exp3_page_fault_exp/    # 实验三：缺页中断
├── exp4_buddy_system/      # 实验四：伙伴系统
├── exp5_slab/              # 实验五：Slab分配器
├── exp6_reclaim/           # 实验六：内存回收
└── exp7_cow/               # 实验七：写时复制
```

### 常用/proc接口
| 文件 | 说明 |
|------|------|
| `/proc/meminfo` | 系统内存信息 |
| `/proc/vmstat` | 虚拟内存统计 |
| `/proc/zoneinfo` | Zone详细信息 |
| `/proc/buddyinfo` | 伙伴系统状态 |
| `/proc/slabinfo` | Slab缓存信息 |
| `/proc/pid/maps` | 进程内存映射 |
| `/proc/pid/smaps` | 进程内存详情 |
| `/proc/pid/status` | 进程状态 |

### 常用sysctl参数
| 参数 | 说明 |
|------|------|
| `vm.swappiness` | swap使用倾向 (0-100) |
| `vm.min_free_kbytes` | 最小空闲内存 |
| `vm.vfs_cache_pressure` | 回收inode/dentry倾向 |
